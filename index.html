About the Project

A compiler is a translator that converts a human-readable programming language into machine-friendly code. This project builds a wizard-themed language where magical keywords and house-inspired rules teach compiler design through a fun and practical workflow.

search

Lexical Analysis

Flex reads the wizard source file and converts character streams into meaningful tokens such as identifiers, numbers, operators, and magical keywords.

schema

Syntax Analysis

Bison validates grammar and structure, ensuring each spell statement follows proper language rules before deeper checks begin.

verified

Semantic Analysis

Symbol table and semantic rules catch misuse of declarations, types, conditions, and function arguments before code generation.
